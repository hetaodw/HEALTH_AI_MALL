# 健康商城前端页面说明

## 页面列表

### 1. 首页 (/)
**功能**：展示 hot_products 表中的热门商品（通常前10个），同时有登录/注册入口以及广告栏

**主要组件**：
- 热门商品展示卡片
- 分类导航入口
- 广告轮播区域
- 登录/注册按钮

---

### 2. 商品列表页 (/products)
**功能**：展示商品的分页列表（每页10~20项），支持按分类、价格区间筛选和排序

**分页作用**：避免一次性加载全部商品，提升性能和用户体验

**筛选功能**：
- 分类筛选：保健品、医疗器械、健康食品、运动健身、母婴用品
- 价格区间筛选：最低价/最高价
- 排序：价格升序/降序、销量、库存

---

### 3. 商品详情页 (/products/:id)
**功能**：展示单个商品的详细信息

**展示内容**：
- 商品封面图和详情图片
- 商品标题、价格、库存
- 商品详情介绍（文字描述）
- 商品评价列表（支持分页）
- 加入购物车按钮
- 立即购买按钮

---

### 4. 搜索页 (/search)
**功能**：用户搜索关键词后，展示匹配商品的分页列表

**典型 URL**：`/search?keyword=蛋白粉&page=1`

**搜索范围**：商品标题和描述

**排序选项**：
- 价格升序 (price_asc)
- 价格降序 (price_desc)
- 最新上架 (newest)

---

### 5. 购物车页 (/cart)
**功能**：管理购物车商品，准备下单

**主要功能**：
- 购物车商品列表展示
- 商品选择/全选功能
- 商品数量修改
- 商品删除
- 已选商品总价计算
- 结算按钮（跳转订单确认页）

**权限**：需要登录

---

### 6. 订单确认页 (/order/confirm)
**功能**：确认订单信息，选择支付方式，完成下单

**主要功能**：
- 收货地址选择（支持选择默认地址）
- 订单商品展示（交易快照）
- 支付方式选择（支付宝/微信/银行卡）
- 订单金额汇总
- 提交订单按钮
- 订单创建成功后展示支付界面

**权限**：需要登录

**流程**：
1. 确认订单信息 → 2. 支付 → 3. 完成

---

### 7. 个人中心页 (/profile)
**功能**：展示个人信息，管理收货地址和订单

**主要功能**：
- **个人信息展示**：用户名、邮箱、手机号、头像
- **头像上传**：支持上传和更换头像
- **收货地址管理**：
  - 查看地址列表
  - 新建/编辑/删除地址
  - 设置默认地址
- **订单管理**：
  - 订单列表展示
  - 按状态筛选（全部/待付款/待发货/待收货/已完成）
  - 订单详情查看
  - 取消待付款订单
  - 订单支付
- **账户设置**：修改密码、退出登录

**权限**：需要登录

---

### 8. 登录页 (/login)
**功能**：用户登录

**主要功能**：
- 用户名密码登录
- 登录成功后跳转首页或来源页
- 底部注册入口链接

---

### 9. 注册页 (/register)
**功能**：新用户注册

**主要功能**：
- 用户名、密码、邮箱、手机号填写
- 身份类型选择：普通用户(USER) / 商家(MERCHANT)
- 头像上传（可选）
- 备注信息（可选）

---

### 10. 商家后台页 (/merchant)
**功能**：商家商品管理

**主要功能**：
- 商品列表展示（仅当前商家的商品）
- 添加新商品
- 编辑商品信息
- 商品上架/下架
- 库存管理

**权限**：需要登录且为商家身份

---

## 页面路由权限说明

| 路由 | 页面 | 是否需要登录 | 特殊权限 |
|------|------|-------------|---------|
| / | 首页 | 否 | - |
| /products | 商品列表 | 否 | - |
| /products/:id | 商品详情 | 否 | - |
| /search | 搜索 | 否 | - |
| /login | 登录 | 否 | - |
| /register | 注册 | 否 | - |
| /cart | 购物车 | 是 | - |
| /order/confirm | 订单确认 | 是 | - |
| /profile | 个人中心 | 是 | - |
| /merchant | 商家后台 | 是 | 商家身份 |

---

## 设计风格

项目采用**拟物化设计风格**，主要特点：
- 立体感按钮和卡片
- 柔和的阴影效果
- 圆角边框
- 渐变背景
- 交互反馈动画

---

## 技术栈

- **框架**：Vue 3 + Composition API
- **路由**：Vue Router
- **状态管理**：Pinia
- **HTTP客户端**：Axios
- **构建工具**：Vite
- **样式**：CSS（拟物化设计）
