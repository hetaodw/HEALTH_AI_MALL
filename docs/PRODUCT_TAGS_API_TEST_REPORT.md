## 根因分析

### 问题 1: 批量生成性能严重下降

**根本原因**:
1. 串行调用 AI 服务，为每个商品单独调用
2. 每个商品调用 AI 服务耗时约 3.4 秒
3. 没有实现并行处理或异步队列

**验证步骤**:
1. 检查 [ProductTagService.batchGenerateTags()](file:///d:/26bs/backend/src/main/java/com/healthmall/service/ProductTagService.java) 方法实现
2. 查看是否有并行处理逻辑
3. 检查 AI 服务调用是否支持批量接口

**修复方案**:
```java
// 方案1：使用并行流
public BatchGenerateResult batchGenerateTags(List<Long> productIds) {
    List<CompletableFuture<Void>> futures = productIds.stream()
        .map(productId -> CompletableFuture.runAsync(() -> 
            generateTagsForProduct(productId), executor))
        .collect(Collectors.toList());
    
    CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
}

// 方案2：实现异步任务队列
public BatchGenerateResult batchGenerateTagsAsync(List<Long> productIds) {
    String taskId = UUID.randomUUID().toString();
    taskQueue.submit(new GenerateTagsTask(taskId, productIds));
    return new BatchGenerateResult(taskId, "PROCESSING");
}
```
