# 毕业设计开题报告

## 一、课题名称

基于微服务架构的健康商城系统设计与实现

## 二、选题背景与意义

### 2.1 选题背景

随着互联网技术的快速发展和人们健康意识的不断提升，线上健康产品消费已成为一种重要的消费方式。传统的线下健康产品销售模式存在地域限制、信息不对称、选择范围有限等问题，难以满足现代消费者对便捷、多样化购物体验的需求。特别是在后疫情时代，人们对健康产品的关注度显著提高，线上健康商城的需求日益增长。

然而，当前市场上的电商平台大多为综合性平台，缺乏针对健康产品的专业化服务，如专业的商品分类、智能化的标签推荐、健康相关的评价体系等。同时，传统电商系统在商品信息管理、用户个性化推荐、智能化标签生成等方面仍存在不足，影响了用户的购物体验和商家的运营效率。

### 2.2 选题意义

本课题旨在设计并实现一个基于微服务架构的健康商城系统，具有重要的理论意义和实际应用价值：

**理论意义**：
1. 探索微服务架构在电商领域的应用实践，为相关研究提供参考
2. 研究大语言模型在电商商品标签自动生成中的应用，推动 AI 技术与电商业务的融合
3. 设计高并发、高可用的电商系统架构，为类似系统的设计提供理论依据

**实际应用价值**：
1. 为用户提供便捷、专业的健康产品购物平台，提升购物体验
2. 为商家提供高效的商品管理和订单处理工具，降低运营成本
3. 通过 AI 自动标签生成技术，提高商品信息管理的智能化水平
4. 实现库存预占、订单状态管理等核心电商功能，保障交易安全

## 三、国内外研究现状

### 3.1 国外研究现状

国外电商平台发展较早，技术相对成熟。Amazon、eBay 等大型电商平台在微服务架构、分布式系统、个性化推荐等方面积累了丰富经验。近年来，随着 AI 技术的发展，越来越多的电商平台开始引入机器学习和深度学习技术，用于商品推荐、用户画像、智能客服等场景。例如，Amazon 利用深度学习算法进行商品推荐，Google Shopping 利用自然语言处理技术优化搜索体验。

在商品标签管理方面，国外电商平台主要依赖人工标注和基于规则的自动标注方法。随着大语言模型的发展，一些平台开始探索利用 AI 技术自动生成商品标签，但仍处于探索阶段。

### 3.2 国内研究现状

国内电商平台发展迅速，淘宝、京东、拼多多等平台在技术架构、用户体验等方面取得了显著成就。在微服务架构方面，阿里巴巴的 Dubbo 框架、Spring Cloud 等技术在电商领域得到广泛应用。在 AI 技术应用方面，阿里巴巴的"小蜜"智能客服、京东的智能推荐系统等都是典型案例。

在商品标签管理方面，国内电商平台主要采用人工标注和基于关键词匹配的自动标注方法。近年来，随着大语言模型的发展，一些平台开始研究利用 AI 技术进行商品标签自动生成，但实际应用案例较少。

### 3.3 存在的问题

当前电商系统在商品标签管理方面仍存在以下问题：
1. 人工标注成本高、效率低，难以满足大规模商品管理需求
2. 基于规则的自动标注方法灵活性差，难以适应商品信息的多样性
3. 缺乏针对健康产品的专业化标签体系，影响用户的购物体验
4. 标签质量参差不齐，影响商品搜索和推荐的准确性

### 5.3 数据库设计

系统采用 MySQL 作为主数据库，Redis 作为缓存数据库，主要数据表包括：

1. **用户表 (users)**：存储用户基本信息
2. **商品表 (products)**：存储商品基本信息
3. **商品详情图片表 (product_details_images)**：存储商品详情图片
4. **热门商品表 (hot_products)**：存储热门商品推荐
5. **收货地址表 (addresses)**：存储用户收货地址
6. **订单表 (orders)**：存储订单基本信息
7. **订单项表 (order_items)**：存储订单商品明细
8. **商品快照表 (product_snapshots)**：存储下单时商品快照
9. **支付记录表 (payments)**：存储支付记录
10. **库存预占表 (stock_reservations)**：存储库存预占记录
11. **商品详情介绍表 (product_descriptions)**：存储商品详细介绍
12. **商品评价表 (product_reviews)**：存储商品评价
13. **浏览记录表 (browsing_history)**：存储用户浏览记录

### 5.4 核心功能实现

#### 5.4.1 用户认证系统

- 采用 JWT（JSON Web Token）进行用户认证
- 密码使用 BCrypt 加密存储
- 支持用户注册、登录、登出功能
- 支持用户角色管理（USER、MERCHANT、ADMIN）

#### 5.4.2 商品管理系统

- 商家可以添加、更新、删除商品
- 支持商品状态管理（在售、下架、缺货）
- 支持商品分类管理
- 支持商品库存管理
- 支持商品图片上传

#### 5.4.3 商品展示系统

- 用户可以浏览商品列表
- 支持按分类筛选商品
- 支持价格区间筛选
- 支持关键词搜索
- 支持热门商品推荐
- 自动过滤下架商品

#### 5.4.4 订单管理系统

- 用户可以创建订单
- 支持订单状态管理（待付款、已付款、已发货、已收货、已取消）
- 支持订单支付（模拟支付）
- 支持订单取消
- 商家可以确认或拒绝订单

#### 5.4.5 库存预占机制

- 创建订单时预占库存
- 支付超时自动释放预占库存
- 支持库存预占状态管理

#### 5.4.6 AI 商品标签生成

- 基于 Qwen3.5-2B 大语言模型自动生成商品标签
- 支持单个商品标签生成
- 支持批量商品标签生成
- 支持手动更新商品标签
- 支持热门标签统计
- 支持按标签搜索商品

### 9.2 基于用户行为的智能推荐系统

利用系统中已有的浏览记录和购买记录数据，构建基于队列的智能推荐系统，为用户提供个性化的商品推荐服务。

#### 9.2.2 推荐队列实现

1. **实时推荐队列**
   - 使用 Redis 作为消息队列，实现实时推荐
   - 用户浏览商品时，异步计算推荐结果
   - 支持推荐结果的缓存和更新

2. **离线推荐计算**
   - 定时任务批量计算用户推荐列表
   - 使用 Spark 等大数据处理框架处理大规模数据
   - 支持推荐结果的预计算和存储

3. **推荐结果管理**
   - 设计推荐结果存储结构，支持多种推荐场景
   - 实现推荐结果的排序和过滤
   - 支持 A/B 测试，优化推荐算法

#### 9.2.3 推荐场景应用

1. **首页推荐**
   - 基于用户历史行为推荐个性化商品
   - 结合热门商品和新品推荐
   - 支持推荐理由展示

2. **商品详情页推荐**
   - 推荐相似商品和关联商品
   - 基于当前商品的标签和分类进行推荐
   - 支持"购买此商品的用户还购买了"功能

3. **购物车推荐**
   - 基于购物车商品推荐搭配商品
   - 推荐互补商品和升级商品
   - 支持满减凑单推荐

4. **搜索结果推荐**
   - 在搜索结果中插入个性化推荐
   - 基于搜索词和用户历史行为优化排序
   - 支持推荐结果的多样性控制

#### 9.3.1 模型蒸馏方案

1. **教师模型选择**
   - 使用更大参数量的模型（如 Qwen-7B、Qwen-14B）作为教师模型
   - 利用教师模型的知识指导小模型学习
   - 支持多教师模型的集成蒸馏

2. **蒸馏训练策略**
   - 知识蒸馏：让小模型学习教师模型的输出分布
   - 特征蒸馏：让小模型学习教师模型的中间层特征
   - 任务蒸馏：针对特定任务（如工具调用）进行专门蒸馏

3. **LoRA 微调优化**
   - 使用 LoRA 技术进行高效微调，降低训练成本
   - 针对工具调用场景设计专门的 LoRA 模块
   - 支持增量学习和持续优化
