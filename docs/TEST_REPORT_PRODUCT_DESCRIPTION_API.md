### 测试2: 创建或更新商品详情介绍

**接口**: `POST /v1/product/descriptions/{productId}`

**路径参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| productId | int | 商品 ID |

**请求头**:
```
Authorization: Bearer {merchant_token}
```

**请求体**:
```json
{
  "content": "商品详细文字介绍内容..."
}
```

**字段说明**:
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | string | 是 | 商品详细文字介绍内容 |

**测试结果**: ✅ 通过

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "id": 1,
    "productId": 1,
    "content": "商品详细文字介绍内容...",
    "createdAt": "2026-02-28T10:00:00",
    "updatedAt": "2026-03-03T10:00:00"
  }
}
```

**说明**: 成功创建或更新商品详情介绍。如果已存在则更新，不存在则创建。

## 商品详情介绍字段说明
| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 详情介绍ID |
| productId | int | 商品ID |
| content | string | 详细文字介绍内容 |
| createdAt | datetime | 创建时间 |
| updatedAt | datetime | 更新时间 |

## 业务规则
1. 每个商品只能有一个详情介绍
2. 创建详情介绍时，如果已存在则更新
3. 删除详情介绍后，商品详情页将不显示详细文字介绍
4. 详情介绍内容支持富文本格式
